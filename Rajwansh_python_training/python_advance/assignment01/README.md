# Python Advanced Assignment 01


## Overview

This folder contains solutions for Python Advanced Assignment 01. The assignment focuses on core and advanced Python concepts including exception handling, iterators, generators, functional programming, regular expressions, testing, packaging, and parallel execution.

The implementation follows Python best practices, including:

* PEP 8 coding standards
* Meaningful variable and function names
* Modular design
* Type hints
* Docstrings
* Exception handling
* Package organization
* Object-Oriented Programming (OOP)
* Single Responsibility Principle (SRP)

The project is organized into separate modules based on the topics covered during training.

## Requirements

Install dependencies:

```bash
pip install -r requirements.txt
```

Or install required packages manually:

```bash
pip install pytest
```

---

## Running Programs

Navigate to the required folder and execute:

```bash
python file_name.py
```

Example:

```bash
python custom_iterator.py
```

---

## Testing

Run all test cases:

```bash
pytest
```

Run a specific test:

```bash
pytest tests/test_addition.py
```
